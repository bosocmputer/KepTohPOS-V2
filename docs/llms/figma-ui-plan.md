## 2. Theme (เปลี่ยนที่เดียว เปลี่ยนทั้งระบบ)
- ไฟล์ `prototype/theme.css` แบ่ง 2 ชั้น
  - **ชั้นสีดิบ:** `figma` (Orange 500 `#FE4E10`, 600 `#EF3408`, 100 `#FFE6D4`, 50 `#FFF4ED`, Neutral 50–950, Green `#16A34A`, Red `#DC2626`, Dark `#141B34`) และ `team` (`#FF7A00`, `#20242C`, `#F4F4F5`, `#172033`, `#16A36A`, `#E5484D`)
  - **ชั้นความหมาย:** `--primary`, `--primary-hover`, `--primary-soft`, `--on-primary`, `--bg`, `--surface`, `--text`, `--text-muted`, `--line`, `--success`, `--danger`, … component ใช้แค่ชั้นนี้
- สลับธีมด้วย `<html data-brand="figma|team">` (ค่าเริ่มต้น `figma`) · `--on-primary`: figma = ขาว, team = เข้ม
- โหมดมืด: `data-theme="light|dark"` + ตามเครื่อง override เฉพาะชั้นความหมาย ต้องใช้ได้ทั้ง 2 ธีม
- ตัวอักษร: ใช้ Anuphan / IBM Plex Sans Thai (SF Pro ไม่มีภาษาไทย) ขนาด 12/14/16 + น้ำหนักตาม Figma · มุมโค้ง 4/8/12/14/16 · เงาเบาตาม Figma
- หน้าตั้งค่า: ตัวสลับธีม (Figma/ทีม) + โหมด (สว่าง/มืด/ตามเครื่อง)

## 3. ข้อมูลและกฎธุรกิจ
### Mock data (JSON)
- `prototype/data/mock-data.js` = `window.KEPTOH_MOCK = { ...JSON ล้วน... }` (ไฟล์ .json อ่านผ่าน file:// ไม่ได้)
- ข้อมูลหลักอยู่ในไฟล์นี้: ร้าน, หมวด, สินค้า (แพ็กเกจบุฟเฟต์เป็นหมวดหนึ่ง), โต๊ะ, พนักงาน, วัตถุดิบ, แหล่งซื้อ, ช่องทางจ่าย
- ยอดขายย้อนหลัง 30 วันยังสร้างด้วยโค้ด (วันที่ต้องอิงวันนี้)
- หน้าตั้งค่า: ปุ่ม **ส่งออก / นำเข้า JSON** + รีเซ็ตเป็นข้อมูลตัวอย่าง

### จ่ายก่อนกิน / กินก่อนจ่าย (ยืนยันกับเจ้าของแล้ว)
- ร้านตั้งค่าเริ่มต้น `shop.payTiming = 'before' | 'after'` และ**เปลี่ยนรายโต๊ะได้ตอนเปิดโต๊ะ**
- แยก **ออเดอร์ของโต๊ะ** (รายการ + จำนวนคน ทุกรอบที่สั่ง) ออกจาก **บิล** (สร้างตอนรับเงินเท่านั้น)
  - จ่ายก่อน: ปุ่ม "รับเงิน" ทุกรอบ → บิลแยกรอบละใบ (พฤติกรรมเดิม)
  - กินก่อน: "ส่งออเดอร์" สะสมรายการ → "เช็กบิล" → บิลเดียว
- การ์ดโต๊ะมีสถานะ "รอชำระ" + ยอดค้าง · เก็บโต๊ะได้เมื่อชำระครบ · ปิดกะต้องเตือนถ้ามีโต๊ะค้างชำระ
- ยอดขายนับตาม **วันที่รับเงิน**
- ลบ/ลดรายการที่ส่งแล้วแต่ยังไม่จ่าย: **ผู้จัดการขึ้นไป + ใส่เหตุผล** (เก็บประวัติไว้)
- ไม่ทำรอบนี้: แยกบิล/หารจ่าย, พิมพ์ใบแจ้งยอด, ส่งออเดอร์เข้าครัว, โหมดร้านอาหาร (แต่โครงสินค้า+หมวดต้องรองรับ)
