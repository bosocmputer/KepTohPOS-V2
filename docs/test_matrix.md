# Checklist ทดสอบก่อนเปิดใช้จริง (Test Matrix)

ใช้ 2 แบบ: เป็นแผนของเทสต์อัตโนมัติ และเป็น checklist ให้ทีมบัญชีกดทดสอบบน staging

- **บทบาท:** `O` เจ้าของ (มีบัญชีเจ้าของล็อกอินอยู่) · `M` ผู้จัดการ · `C` แคชเชียร์ · `D` เครื่องที่ไม่มีบัญชีเจ้าของล็อกอิน
- **โหมด:** `ON` ออนไลน์ · `OFF` เน็ตหลุด (ใช้ได้หลัง M2) · `2D` สองเครื่องพร้อมกัน (ใช้ได้หลัง M3)
- **ร้าน:** `NV` ไม่จด VAT · `VI` จด VAT ราคารวม VAT · `VE` จด VAT ราคาไม่รวม VAT
- **อัตโนมัติ:** ชื่อไฟล์เทสต์ที่ครอบคลุม (`E2E` = เทสต์บนเบราว์เซอร์ใน `app/integration_test/` รันด้วย `scripts/e2e.sh`) หรือ `มือ` ถ้ายังต้องกดเอง
- **สถานะ:** ⬜ ยังไม่ทดสอบ · ✅ ผ่าน · ❌ ไม่ผ่าน (ใส่เลข issue)

### 9.1 รายการตรวจรับ UAT สำหรับคุณอัย (ฝ่ายบัญชี) บน Staging (`https://keptoh-staging.vercel.app`)
1. **การคำนวณ VAT หลังหักส่วนลดปัดเศษ (`VA-07`):**
   - ทดสอบทั้งโหมด **ราคารวม VAT (`included`)** และ **ราคาไม่รวม VAT (`excluded`)** เมื่อมีค่าบริการ (Service Charge) หรือส่วนลดปัดเศษสตางค์ลงเป็นบาทถ้วน
   - ตรวจบนใบเสร็จและในรายงานภาษีขายว่า `ภาษีมูลค่าเพิ่ม (VAT 7%) = round(ยอดสุทธิที่รับจริง × 7 ÷ 107)` และ `มูลค่าสินค้า/บริการก่อนภาษี = ยอดสุทธิ − VAT` ทุกบิลบวกกันตรงกับยอดรวมท้ายรายงาน
2. **การยกเลิกและออกใบใหม่แทนในเดือนภาษีเดียวกัน (`VA-05` — ป.86/2542 ข้อ 25):**
   - เปิดบิลในหน้า `/bills` ด้วยสิทธิ์เจ้าของ/ผู้จัดการ ➔ กด **"ออกใบใหม่แทน"** (เช่น เปลี่ยนช่องทางชำระเงินจากเงินสดเป็นโอน)
   - ตรวจว่าบิลเดิมถูกสถานะยกเลิก (ไม่ถูกลบเลขที่ ในรายงานภาษีขายแสดงยอด `0.00` พร้อมหมายเหตุยกเลิก) และบิลใหม่ได้เลขลำดับถัดไป พร้อมพิมพ์บรรทัด **"ยกเลิกและออกฉบับใหม่แทนเลขที่ …"**
   - ตรวจว่าบิลของเดือนก่อนหน้าไม่สามารถกดออกใบใหม่แทนได้
3. **การออกใบกำกับภาษีเต็มรูปเมื่อเครื่องไม่มีรหัส RD (`VA-03`, `VA-04` — กค 0811/พ.9254):**
   - ตั้งค่าเครื่อง POS ให้ว่างรหัสประจำเครื่องสรรพากร (`rd_machine_code = null`) แล้วรับชำระเงิน ➔ ตรวจว่าหัวใบเสร็จเป็น **"ใบเสร็จรับเงิน"** (ไม่มีคำว่าใบกำกับภาษีอย่างย่อ)
   - เปิดบิลดังกล่าวในหน้า `/bills` ➔ กด **"ออกใบกำกับเต็มรูป"** กรอกชื่อ ที่อยู่ เลขผู้เสียภาษี 13 หลัก และสาขาของผู้ซื้อ ➔ ตรวจว่าได้ใบกำกับภาษีเต็มรูปเลขชุด `{สาขา}-F-000001` อ้างอิงเลขใบเดิม และเมื่อเปิดดูใบกำกับภาษีเต็มรูปจะต้อง **ไม่มีปุ่ม "ออกใบใหม่แทน" หรือ "ออกใบกำกับเต็มรูป" ซ้ำ**
4. **บิลรับเงินปกติในร้านจด VAT (`VA-03`, `VA-06`):**
   - ตรวจในหน้า **รายงาน ➔ แท็บ ภาษีขาย** ว่าบิลจากเครื่องที่ยังไม่มี `rd_machine_code` แสดงในตารางรายงานและนับรวมยอดฐานภาษีและภาษีขายครบถ้วน
5. **ช่วงเลขที่สรุปรายวันรายเครื่อง & ส่งออก CSV (`VA-06`):**
   - ตรวจตาราง **"สรุปรายวันแยกตามเครื่อง"** ด้านล่างรายงานภาษีขาย ว่าแสดงช่วงเลขที่เริ่มต้น–สิ้นสุด (`fromNo` – `toNo`), จำนวนบิลปกติ, จำนวนบิลยกเลิก, มูลค่าก่อนภาษี, VAT และยอดสุทธิ แยกรายเครื่อง (เช่น `POS10`) และแยกแถวใบกำกับเต็มรูป (`FULL`) ถูกต้อง รวมถึงกดดาวน์โหลดไฟล์ `.csv` เปิดใน Excel ได้ตรงกัน

## 11. ขั้นตอนกดทดสอบมือบน Staging (Manual Verification Protocol — M6-E)

### 11.1 ทดสอบเปิด 2 เบราว์เซอร์พร้อมกัน (Multi-Device Realtime & Alias Merge)
1. เปิด `https://keptoh-staging.vercel.app` บน 2 หน้าต่างเบราว์เซอร์แยกกัน (เช่น Chrome ปกติ = เครื่องที่ 1, Incognito หรือ Safari = เครื่องที่ 2 ที่ผูกเข้าร้านเดียวกัน)
2. เข้าสู่ระบบด้วย PIN บนทั้ง 2 เครื่อง และเปิดดูหน้า **โต๊ะ (`/tables`)** พร้อมกัน
3. **ทดสอบส่งออเดอร์ข้ามเครื่อง (`MD-02`):** บนเครื่องที่ 1 เปิดโต๊ะ `T1` เลือกแพ็กเกจและกดบันทึก ➔ สังเกตเครื่องที่ 2 ว่าสถานะโต๊ะ `T1` เปลี่ยนเป็นเปิดใช้งานภายใน ~1 วินาที โดยไม่มีหน้ากากหมุน (`BusyOverlay`) บังการกดปุ่มบนเครื่องที่ 2
4. **ทดสอบเปิดโต๊ะเดียวกันชนกัน (`MD-01`):** ตอนออฟไลน์สั้นๆ หรือกดเปิดโต๊ะเดียวกันจาก 2 เครื่องพร้อมกัน ➔ เมื่อซิงก์แล้ว ทั้งสองเครื่องต้องเห็นรายการรวมอยู่ในโต๊ะเดียวกันผ่าน `table_session_aliases` โดยข้อมูลไม่ทับกัน

### 11.2 ทดสอบป้าย Offline Sync และถาดรายการค้างส่ง (Offline Outbox & Sync Center)
1. เปิด Chrome DevTools ➔ แท็บ **Network** ➔ เปลี่ยนเป็น **Offline**
2. สังเกตแถบเตือนด้านบน (`SyncStatusBanner`) แสดงสถานะออฟไลน์
3. ทำรายการเปิดโต๊ะและรับชำระเงินสด 1 บิล ➔ ตรวจว่าได้เลขใบเสร็จทันที และบนแถบสถานะแสดง **"รอส่ง X รายการ"**
4. ไปที่หน้า **บิล (`/bills`)** ➔ ตรวจว่าบิลที่เพิ่งรับเงินมีป้าย **`⏳ รอส่ง`** กำกับ
5. กดที่ป้ายสถานะซิงก์บนหัวจอเพื่อเปิดถาด **`SyncCenterSheet`** ➔ ตรวจรายการค้างส่ง เวลาที่สร้าง และปุ่ม **"ส่งตอนนี้"**
6. ทดสอบกด **"ปิดกะ"** หรือ **"ออกจากระบบ"** ขณะยังมีคิวค้าง ➔ ระบบต้องแสดงหน้าต่างเตือนยืนยันก่อนเสมอ (`OF-09`)
7. เปลี่ยน Network กลับเป็น **Online** (หรือกดปุ่ม **"ส่งตอนนี้"**) ➔ ตรวจว่ารายการค้างส่งหายไป ป้าย `⏳ รอส่ง` บนบิลหายไป และเลขใบเสร็จบนเซิร์ฟเวอร์ตรงกับตอนออฟไลน์ (`OF-01`, `OF-08`)

### 11.3 ทดสอบรายงานและบิลย้อนหลังเกิน 7 วันทำการ (Older-Day RPCs — M4)
